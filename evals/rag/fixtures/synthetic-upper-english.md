# Reading for evidence

<!-- page: 1 -->

## Claims and evidence

A claim states an idea about a text. Evidence is an exact detail from the passage that supports the claim. A learner can test the link by explaining how the chosen words make the claim more believable.

## Main idea and details

The main idea is the point that several details work together to support. A useful prompt asks which detail would be hardest to remove while keeping the same main idea.
